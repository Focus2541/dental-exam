# แอปตรวจฟันนักเรียน (อนามัยโรงเรียน) CUP บวกหมื้อ

| แอป | ลิงก์ | ใช้ทำอะไร |
|---|---|---|
| กรอกผลตรวจฟันนักเรียน | https://focus2541.github.io/dental-exam/entry.html | กรอกผลตรวจ ช่วยกันกรอกหลายเครื่อง พิมพ์ใบแจ้งผลและรายงาน |
| เตรียมแบบตรวจฟันนักเรียน | https://focus2541.github.io/dental-exam/ | พิมพ์แบบตรวจเปล่าไว้เขียนมือ |

## ติดตั้ง (ครั้งเดียวต่อเครื่อง)

เปิดลิงก์ใน Chrome แล้วกด **ติดตั้งเป็นแอป** บนหน้าปก หรือเมนู ⋮ > ส่ง บันทึก และแชร์ > ติดตั้งหน้าเป็นแอป

## วันออกตรวจ

**คนนำทีม (คนเดียวต่อโรงเรียน)**
1. เปิดแอปกรอกผล ใส่ไฟล์รายชื่อของโรงเรียน (Excel, Word หรือ PDF)
2. ตรวจว่าชื่อโรงเรียนและจำนวนนักเรียนถูก แล้วกด **เริ่มกรอกผลตรวจ**
3. ถ้ามีคนช่วยกรอก กด **👥 เปิดให้คนอื่นช่วยกรอก** (ทำครั้งเดียว)

**คนช่วยกรอก**
1. เปิดแอปกรอกผล กดชื่อโรงเรียนในกล่อง **โรงเรียนที่กำลังตรวจอยู่** (หรือกดลิงก์ที่คนนำทีมส่งใน LINE)
2. เลือกห้องของตัวเองแล้วกรอก ไม่ต้องอัปโหลดรายชื่อซ้ำ

ไม่มีสัญญาณก็กรอกต่อได้ แอปจะส่งขึ้น Google Sheet เองเมื่อมีเน็ต

## หลังตรวจ

เมนู **🖨 พิมพ์**: ผลตรวจห้องนี้ / ใบแจ้งผลผู้ปกครอง / รายงานสรุป
ก่อนพิมพ์ใบแจ้งผล เลือก **ผู้ตรวจ** ในตั้งค่าใบแจ้งผล ชื่อและลายเซ็นจะพิมพ์ให้เอง
เพิ่มรายชื่อผู้ตรวจและลายเซ็นได้ที่ **👤 เพิ่ม/แก้รายชื่อผู้ตรวจและลายเซ็น** (เพิ่มครั้งเดียว ทุกเครื่องในเครือข่ายเลือกได้)
