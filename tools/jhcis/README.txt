จับคำสั่ง JHCIS ตอนบันทึกผลตรวจฟัน (ใช้ครั้งเดียว เพื่อทำสคริปต์ลงข้อมูลอัตโนมัติ)

ใช้กับ JHCIS ฉบับทดสอบในเครื่องตัวเอง (localhost) เท่านั้น

1. ตั้ง JHCIS ในเครื่องนี้ให้ต่อฐานข้อมูลทดสอบ (ไฟล์ database: SERVER=localhost)
2. ดับเบิลคลิก เริ่ม_จับคำสั่ง_JHCIS.bat
3. กด Enter ผ่านค่าตั้งต้น (localhost / 3333 / jhcisdb / root) แล้วใส่รหัส root ของ MySQL
4. เปิด JHCIS เลือกเด็ก 1 คนที่มี visit วันนี้ เข้าหน้าตรวจฟัน/อนามัยโรงเรียน
   กรอกตัวเลขให้ต่างกันทุกช่อง ติ๊กให้ครบทุกตัวเลือก แล้วกดบันทึก
5. กลับมาที่หน้าต่างดำ จดสั้น ๆ ว่ากรอกอะไร แล้วกด Enter
6. ส่งไฟล์ jhcis_capture_xxxx.txt ที่ได้ให้ Claude

โปรแกรมนี้ไม่แก้และไม่ลบข้อมูลใน JHCIS แค่เปิดบันทึกคำสั่งของ MySQL ชั่วคราว แล้วปิดคืนให้
