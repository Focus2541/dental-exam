JHCIS อนามัยโรงเรียน (โปรแกรมสำเร็จรูป) รุ่น 1.2
================================================
ใช้ได้กับทุก รพ.สต. ทุกโรงเรียน (ไม่ผูกกับชื่อโรงเรียน)

มีอะไรใหม่ในรุ่น 1.1
  - แท็บ 3 ลงผลตรวจฟันทั้งห้องจากไฟล์ ลงJHCIS_โรงเรียน.csv (แอปกรอกผลตรวจฟัน)
    จับคู่ด้วยชื่อในฟอร์ม Dental  ลำดับใน JHCIS ไม่ต้องตรงกับไฟล์  เลื่อนตารางลงเองจนครบห้อง
    ข้ามเด็กไม่มา / ไม่มีในไฟล์ / ที่บันทึกไปแล้ว  สะกดชื่อต่างกันเล็กน้อยก็จับคู่ได้
  - แท็บ 0 เพิ่มปุ่มจดตำแหน่งลูกศรแถบเลื่อนตาราง "ตรวจทันตกรรม" และปุ่มจดผู้ให้บริการ (เลือกชื่อทันตบุคลากรให้ทุกคน)
  - แท็บ 3 ติ๊ก "บันทึกซ้ำคนที่ลงไปแล้วด้วย" ใช้แก้ผู้ให้บริการ/ผลที่ลงไปแล้ว

ก. สร้างโปรแกรม (ครั้งเดียว บนเครื่องที่มี Python)
  1. แตกไฟล์ zip นี้ไว้ เช่น D:\JHCIS_School_src
  2. ดับเบิลคลิก build_exe.bat  รอ 3-5 นาที
  3. ได้โฟลเดอร์ dist\JHCIS_School  -> คัดลอก "ทั้งโฟลเดอร์" ใส่แฟลชไดรฟ์

ข. ติดตั้งที่ รพ.สต. ลูกข่าย (ไม่ต้องลง Python)
  1. คัดลอกโฟลเดอร์ JHCIS_School ลงเครื่อง เช่น D:\JHCIS_School  แล้วดับเบิลคลิก JHCIS_School.exe
     (ถ้าขึ้นกล่องสีฟ้า "Windows protected your PC" กด More info -> Run anyway)
  2. ด้านบน: โปรแกรมอ่าน IP เครื่อง server จาก C:\Program Files\JHCIS\database.properties ของเครื่องนั้นเอง
     ใส่รหัสผ่าน MySQL (root) แล้วกด "ทดสอบการต่อ"  ต้องเห็นชื่อ/IP เครื่อง server ของ รพ.สต. นั้น
  3. แท็บ 0 (ครั้งแรกของแต่ละเครื่อง เพราะจอไม่เท่ากัน): เปิด JHCIS ค้างไว้ แล้วจดตำแหน่งทีละปุ่ม
       - ใส่ชั้นเรียน  - เพิ่มเด็กใหม่  - ฟอร์มผลตรวจฟัน  - ลูกศรแถบเลื่อน ▲▼ (หน้า ตรวจทันตกรรม)
     แล้วกด "เช็กตำแหน่งฟอร์มผลตรวจฟัน" ดูว่าเมาส์ชี้ตรงทุกช่อง
     (เครื่องที่ความละเอียดจอ/Scale และรุ่น JHCIS เหมือนกัน ก๊อปโฟลเดอร์ "ข้อมูลเครื่อง_..." ไปใช้ได้ แต่เปลี่ยนชื่อให้ตรงชื่อเครื่องใหม่)

ค. ใช้งานแต่ละโรงเรียน (ทำตามลำดับ)
  1. แท็บ 1: เลือกไฟล์รายชื่อนักเรียน (Excel/Word) -> เทียบกับ JHCIS (อ่านอย่างเดียว)
  2. แท็บ 2: ตั้งลำดับโรงเรียนในรายการของ JHCIS เครื่องนั้น (กด "เดาให้")
     ใส่ชั้น 3 คน -> ใส่ชั้นทั้งหมด -> เพิ่มเด็กใหม่ 3 คน -> เพิ่มเด็กใหม่ทั้งหมด -> กลับแท็บ 1 เทียบซ้ำ
     ** ต้องทำขั้นนี้ก่อน เด็กถึงจะขึ้นในหน้า "ตรวจทันตกรรม" ของชั้นนั้น **
  3. แอปกรอกผลตรวจฟัน: กรอกผล แล้ว ⋯ เพิ่มเติม > ไฟล์สำหรับลง JHCIS ได้ ลงJHCIS_โรงเรียน.csv
  4. JHCIS: เปิด visit/Authen ตามที่หน่วยทำปกติ แล้วเปิด "บันทึกข้อมูลงานอนามัยโรงเรียน"
     เลือกวันออกบริการ โรงเรียน ชั้น แล้วกด "ตรวจทันตกรรม" ค้างไว้
  5. แท็บ 3: เลือกไฟล์ .csv เลือกห้องให้ตรงกับชั้นที่เปิดใน JHCIS
     ซ้อม 2-3 คนก่อน -> "บันทึกจริงทั้งห้อง" (ถาม 3 คนแรก แล้วทำต่อเอง)
     จบแล้วดูสรุป "ลงJHCIS_ผล_ห้อง_เวลา.txt" ว่าใครต้องลงเอง (ไม่เจอในตาราง = ชั้นใน JHCIS ยังไม่ถูก)
     กดซ้ำได้ คนที่บันทึกแล้วจะข้ามเอง
  6. แท็บ 4: ตรวจความพร้อมรายงาน 43 แฟ้ม

กฎความปลอดภัย (สำคัญ)
  - ก่อนบันทึกลงฐานจริง: สำรองฐานข้อมูล และดูให้แน่ใจว่า JHCIS ต่อเครื่อง server จริงของหน่วย
  - แป้นพิมพ์ต้องเป็น ENG  ระหว่างโปรแกรมคลิกอัตโนมัติ ห้ามจับเมาส์/คีย์บอร์ด
  - หยุดฉุกเฉิน = ลากเมาส์ไปมุมซ้ายบนสุดของจอ
  - ไฟล์รายชื่อ/ผลเทียบ/บันทึกในโฟลเดอร์ "ข้อมูลเครื่อง_..." มีข้อมูลเด็ก ลบเมื่อเสร็จงาน
  - ไม่เก็บรหัสผ่านไว้ในไฟล์ ต้องพิมพ์ใหม่ทุกครั้งที่เปิดโปรแกรม
